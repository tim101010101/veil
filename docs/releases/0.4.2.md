# Veil 0.4.2

This is the first GitHub CLI release. Veil is early, pre-1.0 software. Read the
[deployment guide](https://github.com/tim101010101/veil/blob/main/docs/deployment.md) before storing real secrets.

## Included

- Native macOS CLI archives for Apple Silicon and Intel.
- Static Linux CLI archives for x86_64 and ARM64.
- Client-side encryption, project secret references, scoped device and OIDC access,
  approval policies, audit, and scoped MCP tools.
- A license, exact source commit, and dependency notices inside every archive.
- Individual SHA256 files and an aggregate `SHA256SUMS` file.

The CLI and server use version 0.4.2. These archives contain the CLI only.
Build and deploy the server separately using the repository documentation.

## Install

Download the archive matching your operating system and architecture, along with its
`.sha256` file. Verify the checksum before extracting and installing the executable.
See [installation](https://github.com/tim101010101/veil/blob/v0.4.2/docs/installation.md) for commands.

## Limits

macOS binaries are not Developer ID-signed or notarized. They may be blocked by macOS.
Checksum verification detects corruption but is not an independent release signature.
Managed `veil upgrade` remains unavailable because release trust keys are not configured.
Install these archives manually and update them using the same method. The bootstrap
installer's managed Linux archive format is not used by these release bundles.

Bitwarden compatibility covers the pinned clients in the compatibility suite, not every
version or feature. CI smoke tests do not exercise interactive Keychain or Touch ID behavior.
This release does not claim a new security audit or production-readiness certification.
